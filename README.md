# Food E-Commerce Data Analysis

## Project Overview

An Excel-based business analytics project focused on analyzing food e-commerce data to identify sales trends, customer behavior, product performance, and key business insights.

## Objectives

- Analyze overall sales and revenue performance
- Identify top-performing products and categories
- Analyze customer purchasing behavior
- Identify sales trends and patterns
- Generate actionable business insights

## Tools & Techniques

- Microsoft Excel
- Data Cleaning
- Excel Formulas & Functions
- Pivot Tables
- Pivot Charts
- Data Analysis & Visualization
- Dashboarding

## Key Analysis

The project analyzes:
- Sales and revenue performance
- Product and category performance
- Customer behavior
- Order trends
- Business performance indicators
